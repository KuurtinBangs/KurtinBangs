# KURTIN BANGS — Press & Booking Website

A static one-page EPK built with plain HTML and CSS. No build tools, frameworks or paid hosting required.

## Preview locally
Open `index.html` in a browser. Keep the `assets/` and `press/` folders next to it.

## Included material
- Band room photo and black-and-white portrait
- DIY door collage and `fishsticks` artwork
- English press release PDF
- Technical rider / stage plan PDF
- SoundCloud link supplied by the band

## Before publishing
1. Replace `[BOOKING EMAIL]` and `BOOKING-EMAIL-HERE` in `index.html` with the public booking address.
2. Confirm the band description, member names and city line.
3. Add a Bandcamp link or embedded player if you want one; only the supplied SoundCloud link is currently included.
4. Add concert dates or a live video when available.

## Free hosting with GitHub Pages
1. Create a public repository on GitHub, e.g. `kurtin-bangs`.
2. Upload `index.html`, `README.md`, and both the `assets/` and `press/` folders.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then save.
5. GitHub will publish the page at `https://YOUR-USERNAME.github.io/kurtin-bangs/`.

The website itself can be hosted for free. A custom domain can be added later, but is not required for the first version.
